# 03. 画面と遷移

スマホ縦画面で、上から下へ読めば使えることを優先します。下部にタブバーを置きます。

| タブ | 画面 |

| ホーム | ホーム |

設定画面は MVP では作らず、1回の品数などは定数にします（必要になったら追加）。

## 1サイクルの流れ

```
S01 ホーム
 │「食べたい料理を選ぶ」
 ▼
S03 献立を組む ─────────────── (plan: draft)
 │ 1. 食べたい料理を1つ以上選ぶ
 │ 2. 提案（追加料理と買う量）を最大3案表示
 │ 3. 1案を選ぶ / 料理を入れ替える / 足りなければ「AIに1品提案してもらう」→ S11相当の確認
 │ 4. 食べる順（1日目・2日目・3日目）と食数を決める。袋の冷蔵/冷凍がここで決まる
 │ 5. 確定
 ▼
S04 買い物リスト ───────────── (plan: shopping)
 │ チェック → 在庫に登録
 │「買い物完了」
 ▼
S05 下ごしらえ ─────────────── (plan: prepping)
 │ 食材ごとに切る。直前に切るものは「切らずに残す」枠
 │「下ごしらえ完了」
 ▼
S06 袋詰め
 │ 料理ごとに袋を確認し（冷蔵/冷凍は確定時の初期値。変更可）、保存
 │「保存完了」
 ▼
S01 ホーム / S02 冷蔵庫ビュー ─ (plan: stored)
 │「今日はこの袋」から、または食べたい袋を選ぶ
 ▼
S08 調理
 │ 直前作業 → 入れる → ボタン → 「作った」
 │ 余った食材の量を確認（在庫に残す）
 ▼
（全部の袋を作り終えたら plan: done）
```

途中で画面を閉じても、献立タブを開けば今の状態の画面に戻ります。

## 各画面の要点

### S03 献立を組む

- 上部: 選んだ料理（anchor）
- 提案カード（最大3案）: 追加する料理名、買い物の点数、余る食材とその量、使える在庫（期限間近は強調）、合計カロリー
- 見出しの右に「別の案を出す」: 出した組み合わせを除いた次の 3 案を出す（見出しは「○回目の3案」、選択は新しい 1 番目に戻す）。出し尽くしたら「これ以上の案はありません」と「最初の案に戻る」。案の番号は回をまたいで続け（2 回目は案4から）、「おすすめ」は 1 回目だけ。何回目か・出した案はタブの間だけ覚え、食べたい料理か食数が変わったら 1 回目に戻す
- 提案カードの中で料理を外す・入れ替えると再計算
- 余りが大きいときは「余る食材で AI に 1 品提案してもらう」ボタン
- 1.6L に収まるか未確認のレシピには注意を表示
- 案を選んだら「食べる順」ステップ: 3 品を並べ替えて 1日目〜3日目を決める（初期値は傷みやすい食材を含む料理が先）。各料理の食数（初期値 1）もここで変えられる。それぞれの袋が冷蔵か冷凍かを表示する

### S04 買い物リスト

- 売り場順（野菜 → 肉 → 魚 → 豆腐・卵・乳製品 → 乾物 → 調味料 → その他）
- 1行: 「玉ねぎ 3個入り × 1（使うのは 2 個）」
- チェックは即時反映（楽観的更新）。通信が切れていても画面上はチェックでき、復帰時に送る（PWA 対応は あるとよい。MVP では TanStack Query のリトライで最低限対応）

### S05 下ごしらえ

```
■ 今切るもの
  玉ねぎ 2個
    ・カレー用 くし切り 1個
    ・スープ用 薄切り 1個
  にんじん 1本 ...

■ 切らずに残すもの（直前に作業する）
  じゃがいも 2個 … 冷凍の袋なので直前に切る（カレー・3日目）
  豆腐 1丁 … 2cm角に切る（麻婆豆腐）
```

### S06 袋詰め

- 袋ごと: 料理名、食べる予定日、中身、冷蔵/冷凍（確定時の初期値）、使用期限、直前作業が残っている食材
- 下味冷凍のレシピは、袋に入れる調味料も表示
- 冷蔵にして使用期限が食べる予定日より前になる場合は警告

### S08 調理

1. 直前作業（例: 豆腐を切る、じゃがいもを切る）
2. 入れる順（袋 → 直前に作業したもの → 水・調味料。下味冷凍なら調味料は袋に入っている）
3. ホットクックの設定（`hotcook_mode`）
4. 冷凍のまま入れる場合の注意（袋が冷凍なら表示）
5. 「作った」→ 余った食材の量を確認

## UI の方針

- 文字は大きめ、タップ領域は 44px 以上
- 期限間近は色だけでなくラベル（「あと1日」）でも示す
- 画面とメッセージは日本語
