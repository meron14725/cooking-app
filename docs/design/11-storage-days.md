# 11. 食材の日持ちの推定

COCORO の取り込みで入れた食材の日持ちと保存場所は、分類ごとの固定値です。分類が分からなかった食材は野菜扱い（冷蔵 7 日・冷凍 30 日）になっているので、グラニュー糖やかつおぶしにも不自然な値が付いています。これを「分類と価格をまとめて推定」の段の 1 つとして入れ直します。

## 対象の列

`can_freeze` / `fridge_days` / `freezer_days` / `pantry_days` / `default_location` / `prepped_fridge_days` / `prepped_freezer_days`（直前の作業 `before_cook_task` と冷凍のまま入れるときの注意 `frozen_cook_note` は対象外）

## 出どころ（`ingredients.storage_source`）

| 値 | 意味 |
|---|---|
| NULL | 取り込みのまま（未見直し）。migration 0010 で列を足したとき、いまある食材はすべて NULL（＝最初の推定で入れ直す。ユーザー決定 2026-11-28） |
| `rule` | 辞書で決めた |
| `ai` | AI に聞いた（答えが範囲外・矛盾・答えなしのときも ai にして、今の値を残す。同じ食材を何度も聞かない。09 の分類の段と同じ） |
| `manual` | 画面で登録した、または日持ち・保存場所の欄を画面で変えた。まとめて推定で上書きしない |
| `researched` | ウェブで調べた値を CSV から反映した（docs/data/README.md）。まとめて推定で上書きせず、分類だけを変えても残す。画面で日持ちを変えたら `manual` |

- 分類（`attributes_source`）・価格（`price_source`）とは別の列にする。日持ちだけを手で直すことがあるため
- 画面で分類だけを変えたとき（日持ち・保存場所の欄は変えていない）は、`manual`・`researched` 以外なら NULL に戻す。日持ちの値はいったん前の分類のまま残り、次のまとめて推定で新しい分類の辞書や AI で入れ直す。`manual` は手で入れた値なので残す。分類と日持ちを一緒に変えたら `manual`
- 初期データ（`seed/ingredients.ts` の食材）も NULL になるが、辞書で初期データと同じ値に戻る（`seed/storageRules.test.ts` で確かめる）

## 段の順

食材の分類・重さ（09）→ **日持ち** → 価格（10）→ レシピの区分・系統（09）

- 辞書は分類ごとに引くので、分類が決まってから日持ちを決める。分類がまだ取り込みのまま（`attributes_source IS NULL`、分類の AI 待ち）の食材は、日持ちの段では飛ばして残りに数える
- 前の段の AI が残っているあいだは、後の段は辞書・ルールだけで進めて数える（09・10 と同じ）
- 返り値に `storage: { updated, remaining }` を足す。画面は 4 つの段の残りがすべて 0 になるまで呼び続け、日持ちの件数と残りも出す

## 辞書（AI なし）

`src/shared/domain/storageRules.ts` の `STORAGE_RULES`。名前と別名を、分類ごとに上から順に見る（「塩さば」を調味料の「塩」にしないため、行ごとに分類を持つ）。

- 野菜・大豆製品・卵・乳製品・そのほかは、名前で当たったものだけ決める（当たらなければ AI）
- 肉・魚・調味料・乾物は、名前で当たらなければ分類の目安（肉・魚 冷蔵 2 日・冷凍 30 日、調味料・乾物 常温 180 日）で決める
- 砂糖・塩は常温 3650 日（初期データと同じ）。辞書の値は AI の範囲（365 日まで）の外でもよい

## AI

- 辞書で決まらなかった食材を `limit` 件ずつ、名前と分類だけ渡して聞く（`estimateStorage`）
- 答えは `validStorage()` で確かめてから保存する
  - 日数は 0〜365 の整数。冷蔵の日数は必須、ほかは null 可
  - 冷凍できない（`canFreeze = false`）なら `freezer_days`・`prepped_freezer_days` を null にする
  - 冷凍できるのに冷凍の日数がない、冷凍できないのに冷凍保存、常温の日数がないのに常温保存、は矛盾として捨てる
- 保存するときは `WHERE storage_source IS NULL` を付け、推定中に画面で直された値を上書きしない
