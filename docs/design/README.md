## 決まっていること

- スマホ向けWebアプリ、自分専用（1ユーザー）
- ホスティング/DB: Cloudflare Workers + D1
- 認証: Cloudflare Access（自分のメールアドレスだけ許可）
- ホットクックのメニュー番号: 初期は手順文のみ。必要になったら列を足す
